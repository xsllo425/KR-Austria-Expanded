############################################################
### KRAUS 奥地利本部 · 州清单触发器
###
### ★★ 2026-09-21 第六轮新增 ★★
###
### 用途：把「奥地利本部」这件事变成可复用的 scripted_trigger，
###       供国策 / 事件 / 决议 / 州级修正 的 every_owned_state 使用。
###
### ★ 为什么必须手写州 id 清单
###   已实测：history/states 里 owner = AUS 的州【恰好 14 个】，
###   四个 crownland（HUN/CZE/CRO/GAL）不持有其中任何一个 ——
###   王领是独立附属国，有自己的领土。
###
###   → 所以 owner = AUS 本身就等于「本部」，
###     但我们仍要显式列出，理由有二：
###       1) 其中 7 个州另有 SLV/CRO/ITA 的 core（族裔区），
###          叙事上属「帝国非德语区」，与「奥地利本部」不同
###       2) 未来若发生领土变动（王领交易 / 战败失土），
###          硬清单比 owner = AUS 更可控
###
### ★ 参考范例
###   common/scripted_triggers/GER triggers (Germany).txt 的
###   GER_is_prussian_state —— 同样是硬编码州 id 列表
###
### ★ 写法说明
###   scripted_triggers 文件【不用包裹块】（裸写法），
###   本项目已核实 KR 全库 112/182 个文件都是裸写法。
############################################################

############################################################
### ★ A · 奥地利本部核心（7 个纯德语州）
###
### 这 7 个州的 core 只有 AUS，是政治线的作用域。
### 大选、天平、派系忠诚度、黑一 —— 都作用在这里。
###
###   4    下奥地利（Lower Austria）—— 维也纳所在
###   152  上奥地利（Upper Austria）
###   153  北蒂罗尔（North Tyrol）
###   775  施蒂里亚（Styria）
###   835  克恩顿（Carinthia）
###   836  萨尔茨堡（Salzburg）
###   942  福拉尔贝格（Vorarlberg）
############################################################
KRAUS_is_austrian_heartland = {
	OR = {
		state = 4
		state = 152
		state = 153
		state = 775
		state = 835
		state = 836
		state = 942
	}
}

############################################################
### ★ B · 奥地利全境（14 个州，含族裔区）
###
### 含 7 个另有 SLV/CRO/ITA core 的州 —— 属「帝国的奥地利部分」，
### 不是「奥地利本部」。用于帝国层面（而非本部政治线）的效果。
###
###   102 卡尼奥拉（SLV）      683  戈里齐亚（SLV）
###   1107 卡拉万克（SLV）     736  伊斯特拉（CRO）
###   488 的里雅斯特（ITA）    783  特伦蒂诺（ITA）
###   39  南蒂罗尔（意大利语区）
############################################################
KRAUS_is_austrian_all = {
	OR = {
		KRAUS_is_austrian_heartland = yes
		state = 39
		state = 102
		state = 488
		state = 683
		state = 736
		state = 783
		state = 1107
	}
}
