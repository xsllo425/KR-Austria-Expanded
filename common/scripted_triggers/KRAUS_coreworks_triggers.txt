# ── shared works team ──
# The team is available when nobody holds it, or when this module already owns it.
# Holding the team is what lets an entry advance; it is given back by the else branch of
# KRAUS_coreworks_daily whenever nothing can advance, so a stalled or invalid project can
# never keep the team away from the pilot.
# Paused, or no longer an independent Austria: wait, keep every accrued day, hand the team back.
